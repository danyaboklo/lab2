# Система моделирования генетических конструкций

## Описание проекта

Учебное приложение для создания и моделирования условных генетических конструкций.

Проект демонстрирует применение объектно-ориентированного программирования на C++:
- создание классов;
- инкапсуляцию;
- композицию;
- агрегацию;
- ручное управление памятью.

Программа не предназначена для проведения реальных генетических экспериментов и используется только в учебных целях.

# Сборка проекта

## 1. Клонирование репозитория

```bash
git clone <https://github.com/danyaboklo/lab2>
```

Перейти в папку проекта:

```bash
cd lab2
```

---

## 2. Создание папки сборки

Создать отдельную папку для файлов сборки:

```bash
mkdir build
```

Перейти в неё:

```bash

```

## 3. Конфигурация проекта

Выполнить:

```bash
cmake ..
```

## 4. Сборка проекта

Запустить сборку:

# Описание основных классов

## DnaSequence

Класс представляет последовательность ДНК.

Ответственность класса:
- хранение последовательности нуклеотидов;
- проверка корректности последовательности;
- вывод информации о последовательности.

---

## Gene

Класс представляет генетический элемент.

Ответственность класса:
- хранение информации о гене;
- управление последовательностью ДНК;
- выполнение действий над геном.

Связь с классом `DnaSequence` реализована через композицию.

`DnaSequence` является частью `Gene` и не существует отдельно от него.

---

## GeneticConstruction

Класс представляет генетическую конструкцию.

Ответственность класса:
- объединение генетических элементов;
- проверка корректности конструкции;
- вывод информации о конструкции.

Связь с классом `Gene` реализована через агрегацию.

Объект `Gene` создаётся отдельно и передаётся в `GeneticConstruction`.  
Удаление конструкции не приводит к удалению объекта `Gene`.

# Используемые возможности C++

В проекте реализованы:

- классы с закрытыми полями (`private`);
- конструкторы с параметрами;
- деструкторы с выводом информации;
- проверка правил предметной области;
- композиция между `Gene` и `DnaSequence`;
- агрегация между `GeneticConstruction` и `Gene`;

  - объектами на стеке;
  - динамической памятью (`new`, `delete`);
  - указателями;
  - ссылками;
  - массивами объектов.
